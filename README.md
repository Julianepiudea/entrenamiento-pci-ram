# Entrenamiento PCI-RAM OPS

Centro de entrenamiento interactivo para la prueba escrita del roster OPS de Prevención y Control de Infecciones (PCI) y Resistencia a los Antimicrobianos (RAM) para preparación y respuesta a epidemias y brotes.

Abrir: https://julianepiudea.github.io/entrenamiento-pci-ram/

21 módulos de repaso, 135 preguntas, examen cronometrado y 9 casos escritos. El progreso se guarda en el navegador (localStorage).
